Dữ liệu HSO Offline

Phiên bản __VERSION__ · PC, Android và iPhone dùng chung file sao lưu.

Sao lưu

File gồm tài khoản, nhân vật, hành trang, pet và bang hội. Giữ file ở nơi riêng tư.

Xuất file sao lưu

Khôi phục

Chọn file .hsosave từ thiết bị khác. Khôi phục sẽ thay dữ liệu hiện tại. Game giữ một bản dữ liệu cũ trước khi nhập.

Sau khi khôi phục, dùng tài khoản và mật khẩu trên máy đã xuất file. Trên iPhone, vuốt tắt hẳn game rồi mở lại; đóng bảng Dữ liệu chưa phải là khởi động lại game.
